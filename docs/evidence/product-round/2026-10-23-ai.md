## New user paths

- AI composer → **Make a small plan** → enter a goal and optional limits → review/edit full message → **Use this draft** (or explicit **Replace chat draft**) → ordinary **Send**. Cancel keeps the original editor value/selection. No service call occurs until Send; the existing controller/Repository handles prepare, execute, persistence, cancellation, unknown-result query and history. The helper cannot bypass `canSend`, change the conversation, or apply after session/permission replacement. 2400-scalar capacity is visible without truncation.
- Persona editor → **Try this draft** before optional expression fields → existing independent-preview endpoint → **Back to editing** → change expression → try the same trial message again. The new attempt uses current unsaved fields; no create/activation/history write occurs. Trial input is editor-session RAM only and is cleared on consent withdrawal. Native system Back and the visible return controls preserve the input through guarded editor callbacks. Existing bottom preview/save controls remain.
- Chat, Drawer/history, planning, Persona management/editor/preview, validation and recovery copy follow the shared English/Chinese locale. User input, Persona names/expression fields, model output and wire enum values remain unchanged. A language switch preserves the current draft. Global language persistence and Settings wiring are Integration-owned.

Existing Drawer/history/new conversation, optimistic outgoing bubble, waiting/cancel/status feedback, read-position preservation, unknown-result recovery and Persona lifecycle rules were inspected and retained. No API/schema changes, third-party dependency additions or new data reads.
