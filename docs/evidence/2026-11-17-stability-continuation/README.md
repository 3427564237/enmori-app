| onePA：后来请求共享较早读取，可接受已到开始时间的活动 | 共享读取完成后，用每个请求已有 `asOf` 再执行 `startAt > asOf`，与既有缓存命中规则一致。真实应用组合的离线测试覆盖 stable、Browse 及合成 Going；不改为响应时的新时钟，也不改 TTL／取消／共享逻辑。[独立时间边界报告](onepa-pending-time-review.md)。 |
