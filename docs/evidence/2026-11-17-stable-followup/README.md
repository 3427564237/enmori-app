## 待确认方案

完整可执行范围、资金公式、验证与回滚见[授权与后端方案](authorization-and-backend-proposal.md)。

1. **建议批准后端最小修复与回归**：只在stable精确读取入场前退休已经过期的共享快照；保留在途替换、取消、读取途中到期的保护。不改API、数据模型、来源范围、TTL、超时，不读旧数据、不自动重试。实现及回归产物完成后再按具体包核对部署；本轮未修改或部署后端。
2. **onePA／初始启动错误诊断**：如现有证据仍不足，准备一个明确启用、最多30分钟／200条的阶段采集窗口。只包含可信request关联、路由模板、有限阶段／结果枚举、HTTP状态与耗时，不记录用户／活动ID、URL、正文、凭据或原始异常。新的诊断字段、存储与清理验证须按现有Q14政策确认：自服务器记录的 loggedAt 满30天立即不可读，随后24小时内物理清理；不能直接把新日志写入不受控存储。
3. **AI后继授权**：先确认是否已手动充值并取得实际到账净USD、有效期、可用余额和外部共用支出证据。可选新一轮上限USD3.40、证据有效期最多7天，但这属于**新增一轮额度**，不是终身累计仍限USD3.40；如要维持累计总上限，必须按完整旧账重算剩余额度。还需确认维护停机、单owner转换和是否允许一次计入额度的验证发送。没有真实资金／价格证据时，旧授权到期后保持AI拒绝准入；不改日期、抹账或释放未知费用预留。
