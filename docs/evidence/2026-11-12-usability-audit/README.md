## UI/UX 优化候选

这些是基于现有流程的建议，不自动成为已批准需求：

1. **活动页面层次**：地区、搜索、计划、来源、时间筛选、排序和分类挤占首屏，首个活动只露出一部分。可压缩低频控件，突出结果与主要筛选。缺图占位重复占用较大卡片空间，也应结合真实覆盖率评估。
2. **已有活动的可操作性**：加载下一页时，现有卡片被统一 `state.busy` 禁用；控制器实际上允许仍然有效的 loadingMore 快照。可在保持账号、有效期及快照校验的前提下保留旧卡片导航。此项为源码确认，未做实机分页复现。
3. **签到提示去重**：无定位时，Permissions 摘要、保存按钮前后出现多段 GPS/天气提醒。合并后更容易理解“可以继续保存”，保留真实缺失信息即可。
4. **预约时间可读性**：日期、时间、IANA 时区需要手填，回执和管理列表显示 ISO UTC。可改善输入辅助，以用户已确认时区的可读时间为主；不能改掉显式时区/DST核对规则。此项为源码审查，非本轮真人预约。
5. **通知续期与保存恢复文案**：已显示到期日，但续期按钮仍叫“启用系统通知”；推荐资料恢复对比还出现 `true/false` 和地区代码。可用“续期”、本地化开关名称和已知地区名称解释动作，保持未知值与数据来源明确。

五张主要页面截图的独立复核没有发现可确认的普通字号溢出或系统栏遮挡。系统手写字体不是本轮认定的产品字体缺陷。隐私告知较长也没有单凭长度被判为缺陷。
