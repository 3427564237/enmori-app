## Review findings resolved before candidate build

1. History selection used the page State context above its Scaffold, so it could not close the page drawer. Correction uses a Builder context below that Scaffold and closes only that drawer before the existing draft confirmation/selection flow. Tests cover no draft and keep/discard without generation.
2. A superseded default GPS capture could read a newer manually acquired point after its await and attach the old default weather choice. Correction binds the continuation to its own capture epoch; late success and late failure leave the newer point and its choices untouched.

Both were reproduced and corrected in the dedicated UI chat (`c40f4dd`); LI reviewed the correction. UI redesign ownership stays in that chat.
