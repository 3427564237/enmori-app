## Delivered source flows

- Home → up to three of today's owned Check-ins → current owned detail → return
  and reread. The device supplies the date/IANA zone; no automatic paging or total
  count is inferred. Foreground/session/content changes retire old facts.
- Own saved Check-in → start new draft → fresh owner read → review/edit copied
  Note/Mood/Activity → explicit existing create. Old ID/time, place label, GPS,
  weather and sharing are excluded from the seed. Current new-Check-in settings
  and the original idempotent uncertain-result recovery remain authoritative.
- Visible user's participation → compare with own saved choices → Event detail
  → return and refresh. Visibility is checked for each page and before opening;
  unavailable own reads do not become an invented `none`. No invitation or booking
  is inferred, and the foreign page is not persisted or accumulated.
- AI conversation → find in current authorized loaded messages → nearby context
  → return with draft preserved. Earlier pages require an explicit action. No
  search term, new private context, automatic send or retry is added to the model.

Integration provides actual router/composition connections, safe scrolling for
the visible-participation entry, awaited detail returns, direct-entry fallbacks,
and current-session/current-route callback checks. The previous locale storage
and both application roots remain connected.
