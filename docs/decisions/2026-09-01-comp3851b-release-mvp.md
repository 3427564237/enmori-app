# COMP3851B Release MVP boundary — 2026-09-01

- **Status:** Approved
- **Decision owner:** LI HOURUI, ENMORI PM
- **Source ID:** S-PM-0901-MVP
- **Scope:** COMP3851B release planning and schedule boundary

The Week 9 delivery target is a **prioritized, demonstrable, and testable COMP3851B Release MVP**. It is not a commitment to implement every confirmed product capability by Week 9.

The current delivery cadence is:

- Sprint 1: academic Weeks 2–3;
- Sprint 2: academic Weeks 4–5;
- Sprint 3: academic Weeks 6–7;
- Sprint 4: academic Weeks 8–9; and
- academic Weeks 10–12: concentrated cross-feature testing, UAT, optimization, compatibility work, defect closure, and release evidence.

Every development Sprint must still produce an integrated, runnable, testable Increment and satisfy its applicable Definition of Done. Weeks 10–12 do not replace testing, review, or platform evidence inside Sprints 1–4 and must not be treated as an automatic buffer for unfinished primary features.

This decision establishes a release-planning constraint only. It does not yet select the exact MVP capabilities, approve a production backlog, resolve open backend/data/UI/algorithm decisions, or permanently remove confirmed capabilities from the wider product scope. The MVP feature set, Must/Should/Stretch priorities, Release Goal, Release Definition of Done, and four-Sprint forecast require a separately reviewed PM decision.
