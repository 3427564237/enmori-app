# Android launcher and splash artwork for ENMORI 1.0

On 18 November 2026, LI selected the messenger bird from the three ENMORI icon proposals. Use the selected bird for the Android launcher and the native splash screen. Update `main` and the existing Android `v1.0.0` release. [Selected artwork](../../assets/branding/messenger-bird.png) · [Earlier Android delivery decision](2026-11-18-li-profile-save-release.md)

Later that day, LI requested separate GitHub Releases for the two builds. Build 90 keeps its original release. The messenger bird update is published as `v1.0.0+92`, with the same signed APK and Android display version `1.0.0`.
