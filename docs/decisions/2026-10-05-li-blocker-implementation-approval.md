Missing actual DisplayName makes target presentation unavailable.

Pair key is SHA-256 of JSON of sorted AccountIds; each new request reference is a random UUID independent of the pair. Missing block/pair authority is unavailable, never an implicit unblocked decision.

`friend_inboxes/{recipientAccountId}/requests/{requestRef}` stores only `{pairKey}`. A bounded document-ID-ordered scan reads at most 20 entries plus one lookahead; cursor is base64url of the last scanned opaque request reference. Invalid cursors fail 400. Mutations remove consumed/expired references; no terminal history/tombstone/replay receipt. Remaining inaccessible expired synthetic data disappears with the isolated test environment.

Fixture block and permanent-deletion helpers use the same transaction and consume pending. Temporary ineligibility prevents actions without consuming pending.
