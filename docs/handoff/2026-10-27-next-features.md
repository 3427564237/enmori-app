本批基于 `857ebcb`，位于 `souma/next-features-20261027`。本地源码实现和相关验证已完成；
尚未部署后端、构建/安装 APK、执行真实双账号或手机验收，也未推送/合并或声明 Release。

## 本批内容

| 功能 | 已实现的行为 |
| --- | --- |
| 公开头像 | 新图/换图保存前说明所有已登录用户可见；旧私有图必须本人选择公开并保存。好友、推荐、好友申请、已忽略用户、动态、活动参与者及资料页使用独立的受认证头像读取。资料受限不隐藏已公开头像，也不开放其他字段。 |
| 活动时间筛选 | 浏览活动提供今天、本周末、未来七天及最早/最晚排序。按设备本地日期比较，仅作用于已加载活动，保留原分类、搜索、分页和来源顺序选项。 |
| 签到引导卡片 | 空笔记可选择“小确幸／一次出门／想记住的一刻”，填入可编辑提示；不覆盖已有笔记，不自动保存或填写心情、位置及分享设置。 |
| 签到关键词搜索 | 历史页搜索入口支持日期范围，匹配本人的笔记、活动及地点名称。逐页展示进度与结果，可停止及继续，失败重试保留原游标，完整/部分/失败明确区分。点击结果走现有原记录读取。 |

## 兼容与边界

- 原 `/v1/me/profile/avatar` GET/PUT 响应仍为原来的三个字段。旧客户端换图会清除已有公开确认。
  新接口为 `/v1/me/profile/shared-avatar` GET/PUT 和 `/v1/users/:username/avatar` GET。
- 仅新增账号记录上的可选公开布尔标记；缺失视为私有，无批量公开、迁移、索引或新依赖。
  图片校验、元数据去除、独立版本、一次写入及未知结果恢复保留。
- 头像读取 `no-store`，账号切换/后台清空显示；返回页面和本人修改后重新读取。
  不提供头像目录，不开放匿名读取、代他人修改或 AI/推荐评分用途。
- 搜索复用既有本人按日读取及不透明游标；固定设备 IANA 时区逐日读取，日期两端均包含。
  权限失效、账号替换、后台和内容变更会撤销结果及迟到响应。
- 头像客户端接入覆盖 `bootstrap.dart` 与 `controlled_demo_app.dart` 两个实际组装入口。
  新客户端使用扩展接口，需要相应后端版本；缺失接口会保留失败/待核对状态，不静默改为私有保存。

## 验收状态

当前是可审查的本地实现。独立评审、Firebase Emulator 集成、真实双账号、后端部署、
APK、物理手机交互/UAT 与 Release 均为 Not Run，不能以 mock 或 widget 测试代替。
真实验收应特别核对非好友/受限资料的头像可见性、旧图确认前后、更换/移除刷新、
匿名拒绝与他人不能修改，以及手机上搜索取消/日期选择/原记录跳转。
第 4–8 项（一周回顾、地图、系统日历、最近浏览、AI 消息定位）未包含在本批中。
