## 已观察的手机流程

除最后的搜索定位复测外，以下功能在 v37 实机验证；v38 仅改 AI 搜索定位与键盘交互。

| 功能 | 本轮实际观察 |
| --- | --- |
| 一周回顾 | 按设备 Asia/Singapore 读取所选全部 7 天；加载中标记不完整，结束才标记完整；可打开原签到 |
| 签到关键词搜索 | 七天范围逐步读取，完成后显示匹配的既有记录；不把尚未读完当成完整结果 |
| 签到引导 | 提示填入可编辑笔记；返回时出现放弃确认；测试草稿明确放弃，未保存签到 |
| 活动时间筛选 | 今天和未来七天产生不同结果；无匹配文案明确限定在当前已加载范围 |
| 原生日历 | 打开 vivo 日历编辑页，标题、开始时间、场馆及 Ticketmaster 链接正确预填；取消后确认放弃，返回活动详情 |
| 无来源结束时间 | ENMORI 显示核对默认时长提示；vivo 编辑器自行给出一小时结束时间，没有伪称来自来源 |
| 地图缺地址保护 | 场馆名存在但完整地址缺失，地图按钮禁用；不使用场馆名或猜测地址替代 |
| 最近浏览 | 看过的活动出现在本次会话列表；重新打开触发新详情读取；清空后显示空状态 |
| 旧头像 | 原头像成功读取，文案明确仍仅本人可见，有显式公开入口；未代用户公开、换图或移除 |
| AI 搜索与跳转（v38） | 搜索既有消息、查看前后文、跳回原文并高亮、键盘恢复、回到最新消息、草稿保留均已观察 |
